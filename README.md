<h2><b>Song Seeker</b></h2>
<h4>An independent modified Android app based on Seeker.</h4>

</div>

Song Seeker is a modified version of Seeker for Android. It is not maintained by, endorsed by, or affiliated with the original Seeker project or its authors.

Song Seeker is a [Soulseek](https://en.wikipedia.org/wiki/Soulseek) client for Android written in C# supporting downloading, searching (including wishlist and filters), sharing, messages, chatrooms, port forwarding, user info, privileges, and more.

This is a modified version of Soulseek.NET. It is not maintained by, endorsed by, or affiliated with the Soulseek.NET project or its authors. The library is used to communicate with Soulseek servers and network peers. The project also references the unofficial [Soulseek Protocol Documentation](https://nicotine-plus.github.io/nicotine-plus/doc/SLSKPROTOCOL.html) implemented by the developers of the [Nicotine+](https://github.com/nicotine-plus/nicotine-plus) client.

- The Soulseek server, which makes this app possible, relies on donations. Donate: [here](https://www.slsknet.org/donate.php)

This app will always be completely free and open source software, no ads, no 'premium' versions or paid features, etc.
